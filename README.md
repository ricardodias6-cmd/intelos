# Intelos

Plataforma privada e modular de conhecimento, decisão, produtividade e inteligência assistida por IA.

## Estado do projeto

Repositório inicial criado. A arquitetura, os componentes open source e as integrações serão incorporados de forma controlada, com registo de origem, versão, licença e alterações efetuadas.

## Princípios

- Privacidade e controlo dos dados
- Arquitetura modular
- Fontes verificáveis e respostas auditáveis
- Separação entre utilização pessoal e profissional
- Independência face a um único fornecedor de IA
- Reutilização responsável de software open source
